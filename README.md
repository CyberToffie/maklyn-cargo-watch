# Maklyn Cargo Watch

An Android app for container cargo watch and bay-plan viewing on board.

Maklyn Cargo Watch is designed to help a watchkeeping officer follow cargo operations, view container positions and keep watch information available when internet access is limited.

## Project status

The next version is in preparation. Its APK and release notes are planned for publication here after review and testing.

## Project focus

- Container bay-plan viewing and position details.
- Discharging and loading operations and their status.
- Watch notes and handover information.
- Offline use on board.

The content and functionality of each release will be described in its release notes.
